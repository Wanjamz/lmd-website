# Image Setup

To display the project photos on the site, copy these files from `V2/` into the React project's `public/images/` folder:

From: `LMD Website/V2/`
To: `LMD Website/public/images/`

Files to copy:
- Baseline 1.png
- Evaluation.png
- UNICEF booklet11.png
- Unicef Booklet.png

You can do this by running in the `LMD Website` folder:
```
mkdir public\images
copy "V2\Baseline 1.png" public\images\
copy "V2\Evaluation.png" public\images\
copy "V2\UNICEF booklet11.png" public\images\
copy "V2\Unicef Booklet.png" public\images\
```
